# 智析 Data Agent｜A07 初赛代码包说明

版本：2026-09-28 当前阶段版。此文件随源码包一起提交；压缩包由 `scripts/package_preliminary_submission.ps1` 从 Git 已提交版本生成，准确提交号以压缩包文件名和附带清单为准。

## 包的定位

这是 A07「企业数据底座智能问析 Agent 系统」当前实现的源码与关键技术文档，供评审查看产品原型的工程结构和实现证据。它不是完整的初赛材料总包，不能替代项目概要、详细解决方案、PPT、演示视频、产品手册及团队过程材料。最终按赛事平台要求由组长统一命名和合并提交。

## 代码与运行

- `apps/web`：React/TypeScript 网页；`apps/api`：FastAPI；`apps/worker`：Celery；`packages`：领域、Agent、查询、评测和统计/建模协议；`infra`：数据库初始化、迁移与容器配置。
- `evaluations`、`tests`、`scripts`、`.github`：固定评测案例、自动化测试、验收/启动工具和 GitHub 质量检查。
- `compose.yaml`、`.env.example`、`pyproject.toml`、`uv.lock`、`package.json`、`package-lock.json`：本地启动及依赖复现。Windows 入口为仓库根目录的 `启动智析DataAgent.cmd`。一般部署按根目录 `README.md`；首次运行需设置自己的密钥并初始化账号。
- 不能把 `.env.example` 的本地演示配置直接用于生产环境。真实模型密钥须通过部署环境注入；包内不提供真实密钥、账号数据库或历史会话数据。

## 目前可据实展示的能力

- 授权数据源接入与元数据目录、字段画像、版本化语义指标和受控只读 SQL 查询。
- 持久化 Agent 会话、自然语言澄清/续问、证据定位、表格/图表及 Markdown、HTML、PDF 报告。相关性（Pearson/Spearman）和 IQR 统计异常的固定模拟数据全链路验收见 `docs/acceptance/ADV-A4-real-stack-browser-2026-09-28.md`。
- 评测中心已有离线固定案例和真实任务记录；固定模型响应的测试成绩不是 DeepSeek 的真实准确率。
- 六类机器学习算法目前仅完成严格任务、结果和推理数据协议及依赖锁定，**尚未完成训练、评估、模型存储/加载、在线推理、隔离执行与对话入口**。见 `docs/acceptance/ADV-B1-model-contracts-2026-09-28.md`。

完整进度以 `docs/project-status.md` 顶部最新记录为准。旧设计和早期验收文档代表当时方案或历史状态，不应被引用为当前功能完成证明。

## 安全与验收边界

压缩包只取 Git 当前提交的白名单路径；本机 `.env`、Docker 数据卷、数据库、依赖目录、缓存、日志、输出文件和未提交改动均不进入包。包中的样例数据库初始化仅供演示，不代表真实企业数据。安全扫描、单元测试及 GitHub 质量检查只证明对应范围；正式生产性能、灾备、未知企业数据源适配、通用脚本沙箱和六算法闭环仍需要分别验收。

如果报告或 PPT 使用 AI 效果图，应标注“设计效果图”，待实装后替换为真实界面截图，不将效果图视作运行证据。
