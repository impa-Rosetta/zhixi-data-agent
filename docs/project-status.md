## 当前推荐执行顺序

1. 建立制造质量语义模型、指标中心和可复现样例数据；
2. 完成确定性语义查询编译、安全策略与只读执行；
3. 接入 DeepSeek V4 Pro，通过模型网关驱动受控工具；
4. 实现可恢复 Agent 状态图、多轮上下文和证据链；
5. 完成问析工作台、图表、分析与报告；
6. 建立黄金评测、安全红队、可观测性和性能门禁；
7. 产品加固并整理比赛交付材料。

## 距离可用产品的关键判断

M2 与 M3 已形成可部署的数据治理与语义底座，但完整 Data Agent 仍需完成 M4 至 M6：查询安全执行、Agent 工具编排和真实问析工作台。M7 至 M9决定分析质量、可靠性以及比赛交付完整度。
