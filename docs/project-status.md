## 当前推荐执行顺序

1. 完成 M2 剩余管理界面并做双数据库浏览器验收；
2. 建立制造质量语义模型、指标中心和可复现样例数据；
3. 完成确定性语义查询编译、安全策略与只读执行；
4. 接入 DeepSeek V4 Pro，通过模型网关驱动受控工具；
5. 实现可恢复 Agent 状态图、多轮上下文和证据链；
6. 完成问析工作台、图表、分析与报告；
7. 建立黄金评测、安全红队、可观测性和性能门禁；
8. 产品加固并整理比赛交付材料。

## 距离可用产品的关键判断

当前系统已经具备安全接入和理解数据库结构的底座，但还不能称为完整 Data Agent。达到首个可用产品版本至少还需要完成 M3 至 M6：语义模型、查询安全执行、Agent工具编排和真实问析工作台。M7 至 M9决定分析质量、可靠性以及比赛交付完整度。
