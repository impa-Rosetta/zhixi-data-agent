## 当前推荐执行顺序

1. 建立制造质量语义模型、指标中心和可复现样例数据；
2. 完成确定性语义查询编译、安全策略与只读执行；
3. 接入 DeepSeek V4 Pro，通过模型网关驱动受控工具；
4. 实现可恢复 Agent 状态图、多轮上下文和证据链；
5. 完成问析工作台、图表、分析与报告；
6. 建立黄金评测、安全红队、可观测性和性能门禁；
7. 产品加固并整理比赛交付材料。

## 距离可用产品的关键判断

M0 至 M6 已形成产品主链路，完成状态沿用此前阶段验收，不表示本日重新做过全部部署回归。M7.1–M7.6 已补齐多轮实时交互、恢复、推荐、统计与图表；M7.7 报告代码已推进到预览、重试与对象清理，但真实 PDF/MinIO 总验收仍未关闭。M8 最新 v0.1.2 草案 9/9 通过并独立复验，模型响应固定、数据库与 API 门禁实际执行，不能标为真实 DeepSeek 准确率或完整 140 组基准。M9 产品加固与比赛最终交付仍待推进。

## 下一优先级与剩余交付

1. 先关闭 M7.7 报告真实环境验收：镜像依赖、中文 PDF、MinIO 存储、Worker 生成、受权预览下载、撤权、迁移与桌面/移动端检查。
2. 继续 M8-E2 的案例扩充与团队人工审阅，不以重复题堆数量；补充数据源故障、缺字段、极值、提示注入及 Agent 行为证明。
3. 实现已批准的 M8-E3 评测持久化、权限、API、页面与恢复，让结果可在产品中查看，而非只在临时脚本报告中。
4. 实现真实模型调用预算，再经用户针对当批范围单独授权后开展 M8-E4 基准；本轮不自动消耗模型费用。
5. 完成 M8 可观测性与隔离沙箱，随后执行 M9 容量/性能、安全、备份恢复、升级回滚、发布运行手册与最终材料。
