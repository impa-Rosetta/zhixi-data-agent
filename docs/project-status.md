## 当前推荐执行顺序

1. 建立制造质量语义模型、指标中心和可复现样例数据；
2. 完成确定性语义查询编译、安全策略与只读执行；
3. 接入 DeepSeek V4 Pro，通过模型网关驱动受控工具；
4. 实现可恢复 Agent 状态图、多轮上下文和证据链；
5. 完成问析工作台、图表、分析与报告；
6. 建立黄金评测、安全红队、可观测性和性能门禁；
7. 产品加固并整理比赛交付材料。

## 距离可用产品的关键判断

M0 至 M6 已形成可部署、可真实问析且证据可追溯的 Data Agent 产品主链路。M7 至 M9继续提升统计与图表分析能力、评测可靠性以及比赛交付完整度。
