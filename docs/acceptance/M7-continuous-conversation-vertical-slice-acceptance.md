## 已交付能力

- `/app` 和 `/app/conversations/{conversation_id}` 使用会话工作区，不再要求用户每轮发起新的分析；
- 页面底部常驻消息输入框，完成后可“继续追问”，运行中可“加入队列”；
- 稳定运行后的新消息在同一 Conversation 中创建新的 Turn 与 AnalysisRun；
- 澄清、等待确认和可重试状态下的回复继续原 Run，不丢失检查点；
- 当前轮执行期间提交的新消息形成排队 Turn，前轮稳定后只激活下一轮并写入一个 Outbox；
- Conversation View 聚合 Turn、Run View、消息、产物、Evidence 与 Validation，并只返回最近 20 轮；
- 历史 `/app/analysis/{run_id}` 技术详情路由继续可用；
- Conversation API 复用工作空间权限，未登录访问返回 401。
