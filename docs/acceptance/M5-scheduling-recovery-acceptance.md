# M5 定时刷新、回收与受控重试子切片验收

- 日期：2026-09-05
- 结论：通过
- 对应计划：M5 子切片五

## 已验收能力

- 每日/每周计划使用 IANA 时区计算，夏令时不存在时刻向后解析，重叠时刻固定选择首次出现；
- 到期计划按 `next_run_at` 排序并以数据库行锁和 `skip_locked` 领取；
- 每个计划槽生成确定性幂等键，重复领取不会创建重复扫描任务；
- 计划推进始终落在当前时间之后，避免调度器因补偿旧槽产生热循环；
- Celery Beat 周期执行计划领取、事务 Outbox 派发和失联任务回收；
- 失联任务最多恢复两次，第三次进入失败终态并同步画像或构建快照状态；
- 连接器瞬时错误仍执行最多两次指数退避重试，永久错误不自动重试；
- 管理员可取消活动任务，并以 `Idempotency-Key` 显式重试失败或已取消任务；
- 显式重试创建可追溯的新任务，保留 `retry_of_job_id`，且不会与活动任务并发。
