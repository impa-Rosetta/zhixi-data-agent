# M7.7-A3 报告 API 与可靠投递验收

- 日期：2026-09-20
- 范围：报告创建、列表、详情 API，权限、幂等、Outbox 与审计
- 设计依据：`docs/superpowers/specs/2026-09-20-m7-7-trusted-reporting-design.md`

## 已完成

1. 新增工作区级报告创建、分页列表与详情接口；
2. 创建请求只接受同一工作区、同一会话内已完成且通过可信校验的分析 Turn；
3. 以 `Idempotency-Key` 保证同一工作区内重复创建不产生重复报告；
4. 报告创建、Outbox 投递意图和审计事件在同一数据库事务中写入；
5. 新增 `analysis.report.requested` 到 `analysis_reports.generate` 的 Outbox 分发映射；
6. 分离报告创建、读取、下载与重试权限，分析员可生成，审计员保持只读；
7. 列表与详情查询均强制工作区隔离；
8. 创建契约拒绝重复 Turn、未知字段和不支持的模板。

## 接口

- `POST /api/v1/workspaces/{workspace_id}/reports`
- `GET /api/v1/workspaces/{workspace_id}/reports`
- `GET /api/v1/workspaces/{workspace_id}/reports/{report_id}`
