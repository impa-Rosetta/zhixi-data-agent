## 安全边界

- 本切片只建立持久化和安全基础，不提供外部数据库连接API，因此不存在伪造连接或扫描结果；
- 密文、nonce和包装密钥不可单独还原凭据，数据库与应用主密钥需要分开保护；
- 生产环境必须替换示例主密钥，并按实际数据节点配置最小私网CIDR；
- 下个切片的驱动连接必须将网络策略授权结果落实到实际连接地址，且仅使用只读权限。
