- 日期：2026-09-05

## 已验收能力

- 连接器协议使用结构化表、字段和预算对象，不接收用户 SQL；
- PostgreSQL 使用驱动标识符组合器，MySQL 使用转义后的标识符，行数上限只来自已校验预算；
- 两个连接器均复用现有 DNS/IP 授权、TLS、只读事务和连接后地址复核边界；
- 单次语句超时限制在 1 至 10 秒，单表行数、字段值数、单值字符数、单表字节数和任务字节数均有硬上限；
- 视图不进入画像目标，二进制、大对象、空间、JSON 及未知复杂类型不读取样例；
- 数据库只负责有界读取，统一画像引擎负责统计、敏感识别、遮罩和失败关闭。

## Compose 真实源验收

使用只读账号对 Compose 中的 PostgreSQL 16.4 与 MySQL 8.4 样例源执行相同预算：

- 每表最多 2 行、每列最多 2 个值、语句超时 3 秒；
- PostgreSQL 产出 9 个样例、77 字节；
- MySQL 产出 9 个样例、71 字节；
- 两者均未超出任务预算，字段顺序与统一契约一致；
- 原始凭据未进入任务参数、画像文档、日志或验收记录。

## 兼容性说明

普通数值、文本和日期时间类型可画像；被安全规则阻止的类型仍生成带 `unsupported_type` 原因的字段画像，因此目录完整性不受影响。画像失败也不会影响已经发布的元数据快照。
