## 产品行为

1. 运行记录按 30 条分页，案例结果按 25 条分页；服务端返回筛选后的总数。类别和状态筛选作用于整个工作空间内当前运行，不再只过滤当前页。
2. 安全失败提示提供“查看失败案例”，直接切到安全/失败筛选并复位案例页；逐案例可查看安全化错误码与失败断言。
3. 可选同空间运行对照：案例摘要、数据快照、语义版本与轨道相同时才计算覆盖率/通过率的百分点变化；不一致时仅并列展示并警告不可直接比较。未取得结果时不伪造差值。
4. API 仍严格校验工作空间与读权限，类别/状态参数使用有限枚举，非法筛选返回 422；对照详情仍走现有受权端点。
