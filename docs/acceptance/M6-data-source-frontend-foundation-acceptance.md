# M6 数据源管理前端基础切片验收

- 日期：2026-09-06
- 状态：通过
- 范围：M2切片六第一阶段，数据源列表、创建向导与连接检测闭环

## 已交付能力

- 开放受保护的`/app/data`路由和“数据管理”主导航；
- 系统管理员、空间管理员和数据管理员可读取数据源，分析员与审计员不会请求连接详情；
- 提供PostgreSQL/MySQL三步接入向导，覆盖基本信息、连接凭据、TLS策略和提交前安全确认；
- TLS默认使用`require`，关闭TLS时明确展示隔离内网警告，证书校验模式强制要求CA证书；
- 创建请求直接调用真实后端，凭据提交后立即清空前端密码字段，不缓存、不回显；
- 数据源列表展示脱敏连接信息、健康状态、TLS策略、配置版本和最近成功时间；
- 创建和重新检测均展示真实异步任务状态与进度，终态后刷新服务器数据；
- API Client支持后端结构化错误对象并保留稳定错误码。
- 本机浏览器同时允许localhost与127.0.0.1来源，并显式允许任务幂等请求头。

## 技术与安全边界

- 使用TanStack Query统一管理服务器状态缓存、失效和任务轮询，认证状态仍由现有AuthProvider负责；
- 连接测试继续通过API事务、Outbox、Celery Worker和Connector执行，前端不模拟进度或成功结果；
- 浏览器只提交凭据，不读取密文；分析员与审计员在前端不触发数据源管理请求，后端Policy Engine仍为最终授权边界；
- 当前切片不包含配置编辑、停启用、目录树、结构差异、采样策略、计划或字段画像界面。
