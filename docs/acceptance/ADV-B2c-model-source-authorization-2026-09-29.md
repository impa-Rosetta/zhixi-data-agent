# B2c 建模权限及可信来源读取

日期：2026-09-29。用户明确批准建模角色权限后实施。

## 实现

增加 model.read、model.train、model.predict 独立动作。系统管理员、空间管理员、数据管理员、分析员拥有三项权限；审计员仅查看。跨空间政策始终拒绝。

新增 apps/api/services/modeling_sources.py。训练来源读取前重新加载当前用户及成员角色，要求 model.train；再复用既有高级分析来源读取器校验空间、完整查询、实际数据摘要、证据、已完成运行、有效数据源与目录/语义发布。确认请求快照与持久化证据、请求摘要与产物实际摘要一致后，返回内部 VerifiedTrainingSource。

不访问源数据库、不写数据、不启动训练、不对外开放新接口。来源校验继承现有 analysis.run 权限，未降低旧边界。审计员不能通过此训练读取函数取得数据。

## 验证

先确认缺少读取模块的失败，再实现。新增 29 项回归：五角色权限、跨空间、快照/摘要不匹配、外部角色降级、账号停用、源禁用、证据失效等。与既有可信读取器专项合计 64 项通过。全量后端 912 项通过、1 条条件跳过；新增代码 Ruff 和读取器严格 MyPy 通过。

## 剩余边界

B2 尚未整体关闭，专用完整查询及不可变训练快照持久化仍待实施。此适配器可安全读取既有完整可信查询，但不代表已有 20000 行专用提取流程。当前 ModelSpec 源摘要使用 query_result 产物摘要，不能误用仅包含行列的 result_digest。

六算法训练、划分后预处理、隔离代理、模型任务/版本持久化、预测和持续会话入口仍未实现。权限动作存在不等于相应功能已开放，也不代表生产就绪。
