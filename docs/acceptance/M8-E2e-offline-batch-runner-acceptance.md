# M8-E2e 离线批量执行编排验收

- 日期：2026-09-27
- 状态：代码级、隔离产品 Agent 集成测试通过；不是 140 组黄金集验收
- 范围：延续已批准 M8-E2 和安全评测方案；不调用真实收费模型

## 实现

新增串行离线批量执行器。每个案例由独立 context manager 提供执行及清理生命周期，适配器负责创建合成夹具、复用产品入口并返回实际观察结果；判分仍由已有确定性评分器完成，适配器不能自行提交通过分数。

运行冻结案例集摘要、版本、合成数据和语义版本，向适配器传递分离副本，避免案例执行过程中改写预期来提高分数。运行结果区分通过、失败、基础设施错误、前置条件不满足和未执行；子集执行保留整个案例集分母。输出安全化 JSON，包括逐项检查、分类汇总、Agent行为/系统门禁分别汇总、安全失败清单和关联产品 Run ID，不输出提问、原始观察、异常详情、SQL 或供应商响应。

案例执行发生异常后仍清理夹具。准备或清理阶段失败时停止后续案例；跨案例复用同一产品 Run ID 同样阻断批次。环境错误不算业务失败或安全通过。清理成功的单个执行错误可继续后续案例。

## 验证

- 先运行红测试，确认执行器模块缺失时测试失败，再实现。
- 编排测试覆盖顺序生命周期、执行错误脱敏、清理失败停止、前置条件 blocked、未知案例、子集分母、Run ID 跨案例复用、预期篡改、准备失败、观察错误码脱敏、安全缺证明和双轨汇总。
- 集成测试为两个案例分别创建隔离内存数据库，调用产品 create_run / run_analysis、冻结 FakeGateway、真实持久化行为采集及数据库前后态采集，不复制 Agent。第二个运行被刻意破坏工具调用计数，结果为一通过一失败，安全失败清单正确列出第二个案例。
- 后端全量 Pytest：355 项通过；严格 MyPy：108 个源文件通过；变更范围 Ruff 通过。前端未变更，没有声称新的浏览器验收。

## 未完成与边界

执行器不使任意第三方适配器自动具备断网能力。这里只使用审阅过的合成隔离夹具和 FakeGateway；不得据 offline 标签自动授权收费模型或在真实企业空间运行探针。
