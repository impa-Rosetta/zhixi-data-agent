# M7.7-B2a 可信报告文件接口验收

- 日期：2026-09-25
- 范围：报告 HTML 预览与 Markdown、HTML、PDF 下载的后端接口

## 已实现

1. 工作空间级预览和三格式下载接口重新校验当前成员的报告下载权限；
2. 只读取状态为 `succeeded` 且未过期的报告文件，客户端不能指定对象键；
3. 从私有 MinIO 读取前限制文件大小，并在响应前校验长度与 SHA-256 摘要；
4. 下载使用附件响应与安全文件名，HTML 预览使用严格 CSP、禁止缓存和 MIME 嗅探；
5. 成功预览和下载记录审计，存储故障及摘要不一致返回稳定错误码；
6. 权限撤销、跨工作空间访问、未完成报告与篡改对象均有自动化测试。
