- 状态：通过

## 已实现

- `sampling_policies`以数据源为边界保存默认关闭的采样授权、Schema/表白名单和六类硬预算；
- 启用策略必须包含普通表，所有表必须属于允许Schema且存在于当前发布目录；视图和不存在对象不能授权；
- 策略使用`version=0`表示尚未持久化的安全默认值，后续更新采用乐观锁；
- `scan_schedules`支持每日、每周、IANA时区、本地时间、星期、启停、下次执行时间和乐观锁；
- 下次执行时间统一存储为UTC，夏令时不存在的本地时间顺延至下一个有效分钟；
- `scan_jobs`预留画像任务、父任务、重试来源、心跳和协作式取消字段；
- 目录快照加入独立画像状态、错误、冻结选项、计数和时间；
- 字段画像和脱敏样例具备工作空间、数据源、快照及字段完整作用域；
- 策略和计划API沿用Policy Engine，管理员可写，分析员和审计员只读；
- 审计只记录启停、计数、频率和版本，不记录Schema、表、字段或样例值。
