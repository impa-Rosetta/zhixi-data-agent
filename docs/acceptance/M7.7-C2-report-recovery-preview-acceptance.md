# M7.7-C2 报告预览与恢复代码验收

日期：2026-09-25。范围：在线 HTML 预览、失败人工重试、Worker 超时恢复、上传残留清理与 Evidence 回链。本记录只代表代码级验收，不宣称 M7.7 整体完成。

## 已验证

- 报告列表的在线预览读取真实受权 HTML；预览嵌入无脚本权限的 sandbox iframe，HTML 自身带离线 CSP 与样式。修复了原渲染器将 CSP 和样式构造后丢弃的缺陷。
- 可恢复的失败允许原 ReportSpec 人工重试；不可恢复错误不会显示重试入口。服务端使用条件更新、工作空间权限、Outbox 和审计。
- 生成任务通过 `attempt_count` 绑定每次尝试。定时恢复超过 15 分钟的 `generating` 报告；最多 5 次尝试，超限转失败。迟到 Worker 不得发布或修改较新尝试。
- 对象键按尝试隔离；部分上传失败会尽力清除已写入对象，避免覆盖下一次生成的文件。
- 已生成报告可从页面返回原会话 Evidence，保持来源可核对。
- 后端全量 Pytest 323 项通过；重点测试覆盖状态机竞争、过期恢复、重试、CSP 与部分上传清理。Ruff 与相关模块严格 MyPy 通过。
- 前端全量 Vitest 63 项、TypeScript 和 Vite 生产构建通过；报告组件变更范围 ESLint 通过。
