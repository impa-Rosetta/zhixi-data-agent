# M8 E2h：指定月份查询的时间边界修复

日期：2026-09-27

## 问题与解决方案

真实查询评测准备阶段发现，时间解析原来仅支持本月、去年、最近三个月等相对时间，不识别 `2026年7月` 或 `2026-07`。这些输入会返回无时间边界，导致下游可能查询全部时间数据，无法准确回答指定月份的问题。

现在增加确定性日历月份解析，生成 UTC 半开区间。例如 2026 年 7 月对应 `[2026-07-01, 2026-08-01)`。不依赖运行当天日期，支持中文月份和数字月份，12 月正确跨年。已匹配的非法月份或超出可表示边界的年月抛出 `query.invalid_time_range`，不会降级为无筛选查询。

保留已有相对时间解析。此切片不扩大未知时间表达的支持范围，不修改数据库数据、权限规则或模型配置。
