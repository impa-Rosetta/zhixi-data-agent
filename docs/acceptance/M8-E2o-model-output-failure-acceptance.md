# M8-E2o 模型输出故障评测验收

日期：2026-09-27。范围：已批准 M8-E2 的异常案例扩展，未新增产品架构。

## 实现与解决的问题

- 未发布草案 0.1.7 从 34 条追加到 37 条，分类为标准21、多轮5、歧义3、异常6、安全2。保留历史版本不变；尚缺103条及团队人工审阅。
- 新增模型无结构化内容、损坏JSON、意图夹带不允许的SQL字段三种故障。FakeGateway仅替代供应商响应；真正调用产品创建运行、模型协议校验、Worker故障持久化与自然语言呈现路径。
- 必须同时验证失败状态、指定稳定错误码、一次协议调用、自然语言故障说明，以及没有工具调用、产物、Evidence或Validation。不把任意失败都判作正确处理。
- 状态被改为成功、错误码被替换、回复变成伪成功三种反例不能通过；观测契约不匹配记为基础设施错误，不计入已评测通过率分母。
- 新版本可由已有评测API发现和创建，37条案例完整持久化由API集成测试验证。CLI默认版本更新为0.1.7，证据文件只允许新建、不覆盖。
