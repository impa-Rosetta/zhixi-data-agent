# M7.1-B 多轮会话共享契约验收

- 日期：2026-09-15
- 结论：通过

## 已交付

- 创建会话和发送消息请求沿用既有运行预算边界，并拒绝额外字段；
- Conversation、Turn、分页和 Conversation View 均使用严格公共响应模型；
- 新增版本固定为 `1` 的 `AnalysisConversationContext`；
- 白名单上下文覆盖指标、维度、日期范围、粒度、过滤、比较、排序、语义版本和最近验证结果引用；
- 首轮 `initial` 与五种追问关系具有稳定字面量契约；
- Context 禁止任意扩展字段，因而不能写入 SQL、凭据、API Key、推理、异常栈和内部队列键；
- 筛选值、集合数量、文本、分页和整个 Context 均有明确上限；
- 公共 Turn 只暴露 `analysis_run_id` 定位能力，不复用 Run 内部自由 JSON。
