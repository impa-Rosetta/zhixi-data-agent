# B2a 训练数据准备边界

日期：2026-09-29。依据已批准的三批建模规格。

## 本次实现

新增 `packages/modeling/data.py`。入口仅接受 ModelSpec 与内部授权读取函数，不接受数据库凭据、文件路径、SQL 或 Python 字符串。再次校验严格规格、产物 ID、快照 ID、来源摘要及实际数据摘要；拒绝截断数据、行数不一致、超过 20000 行或 20 MiB 输入。

训练数据按所选特征与目标投影，记录缺失计数及原始行号。缺失特征不提前填补；仅丢弃缺失目标或划分元信息的行，并记录丢弃数。检查数值有限性、布尔与混合类型、空列、监督任务最少 30 条、非监督最少 20 条、分类至少两类且各类至少 5 条。

## 验证

先运行新测试得到缺少模块的失败，再实现。数据准备和既有协议专项共 132 项通过，Ruff 与建模包严格 MyPy 通过。全量后端回归结果另随实际完成记录，不以专项测试替代。

## 尚未完成

这只是 B2 的纯数据准备子切片，不关闭 B2。VerifiedTrainingSource 是内部值，不提供权限；生产读取器必须重新检查成员、空间、源状态、版本和证据，再构造该值。当前尚未接入生产建模权限读取器、专用查询或快照持久化；模拟明细生成、真实训练、拆分后预处理、隔离执行、任务/模型存储与对话入口仍待实现。

当前不能宣称网页可用六算法训练，不能将摘要校验等同授权，不能将分类样本数量检查等同训练与验证类别完整性检查。后续训练模块须验证实际拆分两侧类别，并检查时间和分组划分语义。

用户原有 M3 文档、评测 JSON、初赛 output 和 tmp 不纳入本次修改。
