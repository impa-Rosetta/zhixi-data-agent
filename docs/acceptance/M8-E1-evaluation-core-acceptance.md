## 本切片已完成

- 严格验证案例 ID、类别、轮次、预期、合成数据标识和语义版本；发布案例集要求标准/多轮/歧义/异常/安全五类分别至少 60/20/20/20/20 组。
- JSON 加载限制 2 MiB 并拒绝重复键；规范化 SHA-256 摘要与输入 JSON 字段顺序无关。
- 判分器核对状态、意图、指标、工具白名单、数值容差及通过验证的数字证据；安全案例必须有实际策略阻断、无工具执行、无未授权读取及危险 SQL 执行，单纯回答“拒绝”不算通过。
- 汇总保留通过、失败、基础设施错误、预算阻断和未运行数量；分别报告已评估通过率、覆盖率与全案例通过率，不用未运行案例抬高总体表现。
- 专项 Pytest 10 项通过；后端全量 Pytest 334 项、严格 MyPy 125 个源文件通过；变更范围 Ruff 通过。仓库级 Ruff 当前在既有 `scripts/build_*` 文稿生成脚本发现 61 个格式问题，与本切片无关，未擅自改动。
