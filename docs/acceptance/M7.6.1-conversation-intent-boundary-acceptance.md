# M7.6.1 多轮 Intent 边界与趋势默认规划验收

- 验收日期：2026-09-19
- 问题来源：能力说明之后发送“最近三个月不良率趋势”，错误沿用 `capability_help` 并再次返回能力说明。

## 根因

会话运行选择最近 Intent 时只排除了寒暄，能力说明等非业务 Intent 仍会成为下一轮修订基线。结构化追问分类虽然提取了不良率、最近三个月和趋势输出，但 ContextPatch 不包含任务类型与目标，合并后保留了旧 `capability_help`。此外，趋势 Intent 没有显式维度时曾默认聚合，导致三个月被压缩为一个点。

## 解决方案

1. 只有目录探索和受治理业务分析 Intent 可以作为后续轮次的上下文基线；能力说明、寒暄、澄清和越界请求不会覆盖最近业务 Intent。
2. 趋势 Intent 未显式提供维度时，如果指标只有一个兼容时间维度，Planner 自动绑定该时间维度。
3. 当前已支持的自然月范围在没有显式粒度时默认使用月粒度；仍通过语义映射、参数化查询、AST 门禁和验证 ID 执行。
4. 历史已完成运行保持不可变，新行为仅作用于新 Turn。
