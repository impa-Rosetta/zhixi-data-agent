# M8-E2b 回答数字证据对应验收

- 日期：2026-09-25
- 状态：本地代码与自动化测试通过，真实数据库/模型链路待验收

查询型回答现在把正文中实际展示的业务数值与查询 Artifact、Evidence、通过的 Validation ID 一并保存在回答消息中。独立核对函数检查数字确实出现在正文、等于同一查询产物中的唯一单行列值、Evidence 指向该 Artifact，且 Validation 通过。缺少引用的旧消息记为 `unverified`；被修改的数字或错误引用记为 `invalid`，不能自动计为正确。

本轮变更不更改中文回答措辞，不把趋势提示中的“1 个时间点”等说明性数字误报成业务指标。覆盖范围仅为现有查询回答中明确展示的单值/单行数值；多行图表、报告以及自由文本中的所有数字仍需后续扩展核对，不应对外宣称已经全覆盖。

验证：专项测试 32 项、后端全量 337 项通过；变更范围 Ruff 与相关 MyPy 通过。真实数据库及 DeepSeek 评测未执行。下一步将把核对结果接入评测运行观察适配器，再开展合成数据上的端到端验收。
