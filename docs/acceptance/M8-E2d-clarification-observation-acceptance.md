# M8-E2d 澄清运行观察验收

- 日期：2026-09-25
- 状态：本地自动化验证通过，真实模型与数据库环境待验收

评测观察器现在单独处理 `waiting_for_clarification`：它核对运行上下文中的澄清请求、用户实际看到的最后一条 Agent 消息及其 `clarification` 交互类型。只有问题一致且没有执行工具、生成产物、Evidence 或 Validation 时，才观察为 `clarification`。记录缺失、消息内容或类型不一致，以及等待期间出现数据工具调用，均观察为 `failed`，不会仅凭运行状态计为通过。

使用现有低置信度真实 Agent 运行测试，覆盖正常提问、消息篡改、交互类型错误、上下文缺失和意外工具调用。后端全量 337 项测试、变更范围 Ruff 和 MyPy 通过。该测试使用内存数据库与 FakeGateway，不代表 DeepSeek 或 PostgreSQL 的真实环境结果；安全拒绝和失败状态仍待独立观察适配。
