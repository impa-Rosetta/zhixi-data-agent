- 验收日期：2026-09-09

## 功能结果

- catalog_exploration 路由执行已注册的 catalog.search；
- 搜索范围限定为运行所属工作空间的非删除数据源；
- 只接受 active_snapshot_id 指向且状态为 published 的目录快照；
- 支持宽泛目录问题和自然语言中出现的表名、字段名；
- 返回数据源显示名、类型、快照、Schema、表/视图、字段名、标准类型、可空性和注释；
- 返回结果数量、截断状态和“不包含样例”声明。

- 生成 authorization_scope 与 sensitive_output Validation；
- 冻结所有使用的 snapshot_id 和工具注册版本；
- 没有发布目录时返回 catalog.not_available，不生成结果 Artifact。
