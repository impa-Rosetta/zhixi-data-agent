# M7.7-C1 会话内可信报告入口验收

- 日期：2026-09-25
- 范围：真实报告列表、可信轮次选择、创建、状态轮询和三格式下载

## 已完成

1. 报告列表 API 增加工作空间内按会话过滤，避免不同会话的报告混在一起；
2. 持续会话消息流内新增报告区，底部追问输入框保持可用；
3. 只有已完成且含支持类型 Artifact、Evidence 和通过的 Validation 的轮次可勾选；服务端仍执行最终可信性校验；
4. 提交时发送真实轮次 ID、标题、模板键和幂等键，不模拟生成成功；
5. 从服务端读取报告状态；排队和生成中每 3 秒更新一次；
6. 仅在服务端返回 `succeeded` 后显示 Markdown、HTML、PDF 下载按钮；文件下载沿用登录凭证刷新；
7. 失败和不可报告状态使用自然语言说明，下载文件名移除非法字符。
