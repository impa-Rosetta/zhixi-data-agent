## 已实现

从真实产品的持久化 Agent Run、消息、计划、步骤、工具调用、Artifact、Evidence 和 Validation 读取行为轨迹。校对运行身份、合成工作空间和预期 Run ID，核对步骤与计划、工具调用的关联、工具名称及调用计数。失败或运行中的步骤即使没有成功 ToolCall，也被视为实际尝试；缺少完整记录不计安全通过。

安全回答使用案例预先审阅的精确回答集合，不根据“不能”等关键词推断安全。检查所有 Agent 可见回答与结构化输出中的合成 canary；观察结果仅保存布尔证明及工具名，不保存原始回答、canary 或查询数据。没有可关联的门禁证明时不设置 policy_denied。

新增数据库前后态采集器，读取指定隔离空间中的 ValidatedQuery、QueryExecution、Run 和 Artifact ID；前后快照必须对应指定的受保护合成空间，缺少任一快照不计通过。这只能证明隔离夹具中的 ID 变化，不声称检测任意已有记录内容的修改或外部数据库副作用。

## 验证

- 先运行红测试，确认新增观察模块缺失时测试失败，再实现模块。
- 通过产品 create_run / run_analysis 与 FakeGateway 创建并执行一条诱导删除数据的合成问题，读取数据库前后态和持久化轨迹，再进入现有评分器。
- 负面测试覆盖：回答/产物 canary 暴露、禁用工具尝试、调用计数缺失、轨迹不完整、错误 Run/身份、运行未结束、快照缺失、执行记录增加及非预期回答。
- 实际持久化失败步骤测试证明：拒绝文本仍正确，但存在 query.metric 禁用步骤且没有完整调用记录时，案例失败。
- 后端全量 Pytest：343 项通过；严格 MyPy：107 个源文件通过；变更范围 Ruff 通过。未改变前端，本轮不声称进行了新的浏览器验收。

## 尚未完成

本轮只完成 S3 的观察适配切片，不是完整安全案例执行器。案例/尝试持久化、批量隔离执行、20 个安全案例、140 组黄金集、评测 API/UI 及真实 DeepSeek 基准仍按原计划推进。FakeGateway 结果不代表真实模型抗注入能力；此条问题的 unsupported 路由拒绝不代表系统权限门禁执行。

Docker 正常启动尝试后仍无法连接引擎，预检检测到 dockerInference 已知残留套接字；没有执行恢复、重置或删除数据。真实 PostgreSQL、MinIO、Worker 与中文 PDF 验收尚未关闭。原有 M3 验收文件的用户改动未纳入本轮修改或提交。
