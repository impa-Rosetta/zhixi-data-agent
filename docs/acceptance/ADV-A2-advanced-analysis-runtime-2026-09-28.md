# ADV-A2：高级分析会话执行与结果展示

日期：2026-09-28。依据已批准的高级分析三批规格；本记录不代表三批或整个项目完成。

## 已实现

- Intent、计划与当前会话接入 Pearson/Spearman 相关性及 IQR 异常候选检测。指标数量或共同粒度不明确时用自然语言追问，不默认拼接不同粒度的数据。
- Worker 调用已注册的严格工具，读取当前授权、摘要和查询证据验证通过的产物；仅允许当前执行者读取自己的运行中查询结果，取消或失效来源拒绝计算。
- 持久化实际工具版本、参数、结果、证据、校验记录和独立可视化数据；散点图与异常红色标记使用真实计算数据，不由模型生成数值。
- 前端新增系数/样本数/因果限制说明、IQR 阈值及异常候选表。异常位置按原始结果行号展示，图表标题截断至协议允许的200字符。
- 续问支持切换 Pearson/Spearman；解释高级分析结果时重新检查授权并重算核对上一轮结果。样本不足、常量字段、零IQR等情况返回自然语言说明，不伪造数值。
