# M8-E2t 缺失信息路由澄清评测

日期：2026-09-27。范围：已批准M8评测设计的歧义案例与自然澄清验证，不改Agent产品行为。

## 新增场景与判分

| 用户问题 | 固定意图输入 | 必须缺失字段 |
|---|---|---|
| 看看最近三个月的趋势 | trend，无指标 | metrics |
| 哪些工单排名最高？ | ranking，无指标 | metrics |
| 不良率与上月对比 | comparison，已有previous_period | time_range |
| 比较本月不良率 | comparison，已有this_month | comparison |

固定模型意图输入独立于黄金期望；实际经过create_run、run_analysis和get_run_view读取持久化结果。核对等待状态、reason_code、missing_fields、自然语言question、resume_node，以及最后一条assistant消息实际展示该追问。工具、产物、Evidence、Validation必须为空，不能以猜指标或预先执行查询取得通过。

原有比较缺少两个周期的案例仍必须请求两个字段。四条新例是不同路由或不同缺失字段，不是仅更换措辞重复计数。反向测试篡改缺失字段、问题（索要数据库密码）或恢复节点，即使篡改问题已展示，也必须判失败。

## 证明边界与待处理缺陷

这些结果验证确定性路由和真实持久化，不证明模型能从自然语言正确抽取意图，也不是DeepSeek准确率。比较追问仍使用现有概括文本，精确缺失字段在结构化请求中核对；没有宣称其文本只询问一个周期。

已只读复现：按设备分析不良率会绑定不受该指标支持的equipment；未知操作员维度提示找不到指标而非维度。该产品行为修复待单独确认，未实施，也未将其计入通过案例。

全套最低数量缺口60条（标准39、多轮8、歧义13），人工审阅未完成。安全仍是系统门禁，不是Agent提示注入证明。M8真实模型基准、全链路观测、沙箱及M9仍未完成。没有改前端、没有重跑浏览器；不动用户原有M3文档及中间证据，不记录真实密钥。
