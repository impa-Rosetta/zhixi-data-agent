## 真实链路验收

在本地 Compose 的真实 PostgreSQL 数据源与平台 API 上完成：

1. 从当前不可变目录选择普通表，启用表级采样，并写入受限预算；
2. GET 回读确认启用状态、单表白名单与每表 5 行预算均生效；
3. 将采样策略完整恢复为关闭、空白名单；
4. 首次创建 Asia/Shanghai 每日 03:30 刷新计划；
5. GET 回读确认时区正确且 next_run_at 位于未来；
6. 将刷新计划关闭，确认 next_run_at 为 null，不会投递定时任务。
