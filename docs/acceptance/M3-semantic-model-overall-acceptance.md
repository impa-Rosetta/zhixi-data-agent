# M3 质量语义模型整体验收

- 日期：2026-09-07
- 结论：通过
- 范围：M3-01 至 M3-05，标准语义模型、指标中心、物理映射、合成数据与映射工作台

## 产品能力

- 建立工作空间隔离的语义模型与版本表，草稿使用乐观锁，发布版本绑定 SHA-256 内容摘要且不可继续修改；
- 定义严格的实体、属性、关系、维度、指标、公式与物理映射契约，重复键、悬空引用和非法公式在写入前拒绝；
- 内置制造质量标准模板：3 个主题实体、22 个属性、1 条关系、4 个维度和 19 个指标；
- 比例指标统一使用 `ratio_of_sums`，明确分子、分母、比例因子与除零返回空值策略；
- 支持从真实目录快照按确定性字段/实体名称生成候选，候选仅提供置信度与理由，管理员确认后才可保存；
- 发布前校验映射字段属于当前工作空间、指定快照与关系，保存的映射必须全部人工确认；
- 提供确定性合成数据生成器，覆盖标准、字段改名和缺列三种结构，并内置固定异常与期望答案；
- 前端 `/app/semantic` 可创建制造模板、检查指标口径、选择数据源与目录快照、确认映射和发布版本。

## 安全与 Agent 边界

- 工作空间管理员拥有管理能力；分析师与审计员只读；数据管理员未被自动扩权；
- 语义引用、物理目录归属和并发版本均由后端裁决，前端状态不能绕过；
- M3 不调用大模型生成指标或映射。后续 Agent 只能读取已发布版本，并通过 M4 编译器消费结构化公式；
- 发布版本不可原地编辑，避免 Agent 执行期间语义口径漂移。
