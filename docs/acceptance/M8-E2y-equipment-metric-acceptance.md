## 独立记录与预期

字段顺序：设备、运行小时、计划小时、停机小时、故障次数、维修小时、理论产量、实际产量。

- 正常：EQ-A(8,10,2,1,1,100,70)、EQ-B(19,20,1,2,2,300,270)。
- 不等权重：EQ-A(1,10,9,2,3,10,5)、EQ-B(80,90,10,3,7,90,70)。
- 零运行量：EQ-A(0,10,10,0,0,100,0)、EQ-B(0,90,90,0,0,900,0)。

| 指标 | 正常 | 不等权重 | 零运行量 |
|---|---:|---:|---:|
| 停机时长（小时） | 3 | 19 | 100 |
| 故障次数（次） | 3 | 5 | 0 |
| 维修时长（小时） | 3 | 10 | 0 |
| 设备可用率（%） | 90 | 81 | 0 |
| 性能效率（%） | 85 | 75 | 0 |

可用率为汇总运行小时/汇总计划小时×100，性能效率为汇总实际产量/汇总理论产量×100。不能直接平均各设备比例。零运行量的计划和理论产量分母有效，结果为0而非NULL。

源记录与黄金数字分别定义，单测独立计算全部15个结果。写入前验证eval_UUID结构名，参数绑定写入bigint和设备text；真实目录扫描、映射发布、Agent、语义编译、安全门禁、只读查询、Evidence/Validation，不覆盖metric_executor。仅查询全部可用事件，模板无设备时间维度，不编造月度趋势。为既有模板扫描保留空质检夹具，不以其数据替代设备数据。
