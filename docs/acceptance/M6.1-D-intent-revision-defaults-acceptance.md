# M6.1-D Intent 修订与默认策略验收

- 验收日期：2026-09-14
- 结论：通过

## 多轮上下文

- 用户补充说明时保留上一轮严格 Intent；
- 新消息通过 IntentRevision 选择 patch 或 replace；
- patch 只允许指标、维度、过滤、时间范围、比较和输出字段；
- replace 必须携带完整、严格验证的新 Intent；
- 同一修订不能同时携带 patch 和 replacement；
- 目标替换后旧绑定、计划、结果、Evidence 引用和澄清均不复用。

## 默认策略

- 普通指标查询未指定时间范围时记录 all_available；
- 未指定维度时记录 aggregate；
- 默认值不修改已发布指标公式，不绕过确定性语义绑定；
- 模型置信度保留用于观测，但不能推翻唯一的本地语义解析结果。

## 恢复与审计

- Intent 修订号和待处理状态进入 AnalysisRun；
- run.intent_revised 记录受验证的 patch/replace 模式；
- run.route_selected 记录确定性路由和绑定要求；
- run.defaults_applied 记录实际采用的安全默认值；
- 所有事件使用现有单调序号和 SSE 重放机制。
