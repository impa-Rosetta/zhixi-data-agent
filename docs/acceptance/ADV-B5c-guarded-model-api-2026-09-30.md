# 受控建模任务 API（ADV-B5c）

日期：2026-09-30。新增工作空间范围的训练任务创建、本人任务状态查询及取消接口。默认 `MODELING_ENABLED=false`，因此部署尚未完成时返回503，不会把排队任务误宣传为可用。启用后必须通过现有登录和工作空间动作权限，再走当前授权的来源校验、快照对象写入和幂等入队；API进程不执行训练，也没有Docker权限。状态响应只含任务ID、状态、次数、时间、安全错误码和成功后模型版本ID，不返回快照或模型字节。撤销来源权限返回403，存储不可用返回不含内部细节的503。

4项HTTP专项测试覆盖默认关闭、受权创建/同键重投/查询/取消、来源撤权及存储故障；全量后端1011通过、1项跳过，覆盖率90.48%；Ruff和严格MyPy通过。此阶段通过的是 SQLite + 对象/来源替身测试，并非真实部署验收。

剩余门禁：真实 PostgreSQL 0015 迁移、MinIO与Docker主机轮询端到端；确认 API 与主机进程部署、镜像ID及健康监控；会话式任务创建/进度/解释/预测/报告和浏览器验收。只有这些通过后才能打开 `MODELING_ENABLED` 并在产品中对外宣称建模可用。
