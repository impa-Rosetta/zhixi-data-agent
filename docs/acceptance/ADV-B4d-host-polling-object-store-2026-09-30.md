# 建模主机轮询与私有对象存储适配（ADV-B4d）

日期：2026-09-30。新增独立主机进程入口 `apps.host.agent`：必须配置精确的本地 SHA256 镜像 ID，轮询有限批次的排队任务和过期租约；领取仍由数据库 CAS 控制；耗尽尝试的租约会转为失败。该进程才持有 Docker CLI 权限，API/普通 Worker 不运行此入口。支持一次轮询参数，便于部署排查；未加入自动启动配置。

新增私有 MinIO 对象适配：只接受代码生成的 `modeling/{workspace}/snapshots|models/{id}/{sha256}.json|skops` 键，限定类型和20 MiB上限；读取只取上限加1字节并关闭/释放连接，不生成浏览器直链。专项替身测试覆盖快照和模型文件读写、非法对象键/类型拒绝、超限读取释放连接，以及轮询派发、耗尽租约回收、非法批量参数。8项专项通过。全量后端1007通过、1项跳过，覆盖率90.46%；Ruff与严格MyPy通过。

明确未验收：以上 MinIO 是替身协议测试，当前 Docker Desktop 未就绪，尚无真实 PostgreSQL 0015 迁移、真实 MinIO、真实 Docker 和重启/多主机故障恢复的联合验收。未接用户 API、会话和网页，不能宣称建模功能对外可用。轮询进程尚需运维配置、健康检查和审计/监控；输入输出目录仍没有宿主文件系统硬配额。
