# M5 画像任务与快照绑定子切片验收

- 日期：2026-09-05
- 结论：通过
- 对应计划：M5 子切片四

## 已验收能力

- 元数据快照先独立发布，再按冻结的策略版本、表范围和预算派生 `profile_scan` 任务；
- 策略不存在、关闭或新快照未命中授权表时不创建画像任务，保持默认零采样；
- 事务 Outbox 只携带任务 ID，连接凭据仅在 Worker 内按数据源密文解密；
- 画像任务具备排队、读取、持久化、完成、失败、重试等待、取消、心跳和进度状态；
- 字段画像和脱敏样例在同一事务中绑定不可变快照，失败时不产生部分画像；
- 画像失败不改变数据源的可用状态，也不撤销已发布目录；
- 终态任务重复投递直接短路，避免重复读取和重复落库；
- 新增快照画像列表、字段详情与任务取消 API，并沿用工作空间授权边界。
