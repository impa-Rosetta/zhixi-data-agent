# M7.3–M7.6 实时会话、推荐、统计与图表验收记录

- 验收日期：2026-09-17
- 验收范围：M7.3 会话事件流、M7.4 中断恢复、M7.5 可执行推荐、M7.6 描述统计与安全图表
- 验收原则：所有结论以持久化状态、证据链、自动化测试和可部署容器为准，不以静态演示页面代替。

## 1. 验收结论

M7.3–M7.6 已形成可用于产品主链路的闭环：

1. 用户在同一会话中连续追问，前端底部输入区无需重新发起分析；
2. 会话事件拥有独立、单调递增的持久化序列，可使用 Last-Event-ID 断线续传；
3. 服务或 Worker 重启后，调度任务可恢复未完成的会话队列；
4. Agent 根据当前结果生成受能力边界约束的后续问题，点击推荐仍进入正常消息、审计与执行链路；
5. 描述统计和图表只从已经验证的查询产物派生，并继承源 Evidence；
6. 前端只渲染版本化、白名单化的 ChartSpec，不接受模型输出任意 ECharts 配置或 JavaScript。

M7.7 Markdown/HTML/PDF 报告编排与导出不在本次验收范围，能力清单仍明确标记为“尚未开放”。

## 2. M7.3 会话级实时事件

### 实现

- 新增 analysis_conversation_events 持久化表与迁移 20260916_0011；
- 每个会话使用 next_event_sequence 分配唯一、递增事件序号；
- Run 事件写入时同步投影到会话事件流，同时保留 run_event_sequence；
- 会话 SSE 支持查询参数游标和 HTTP Last-Event-ID；
- 前端记录最后事件序号，断线重连后从检查点继续并刷新服务端投影；
- SSE 事件名过滤换行，事件内容统一 JSON 序列化，避免事件注入。

### 验收标准

- 重复连接不会重复展示已经确认的事件；
- 跨多个 Turn 的事件保持同一会话序列；
- 页面刷新或网络中断后可以从服务端恢复；
- 不依赖浏览器本地模拟运行状态。

## 3. M7.4 取消与恢复

### 实现

- 仅允许取消当前活动 Turn，并复用 AnalysisRun 的协作式取消协议；
- 下一 Turn 在当前 Turn 终止后按序激活，避免同一会话并行写上下文；
- 定时任务 analysis_conversations.recover_queues 扫描并恢复重启前的排队/运行状态；
- 恢复动作写入 turn.recovered 事件，便于前端和审计追踪；
- Outbox 与幂等键继续保证任务投递可重试而不重复创建 Turn。

### 验收标准

- 取消、失败或完成后队列均可推进；
- Worker 重启不会永久卡住后续问题；
- 恢复操作不会越过工作空间和会话边界；
- 用户可看到自然语言状态，内部错误码只进入技术详情。

## 4. M7.5 可执行后续推荐

### 实现

- 推荐由 recommend_follow_ups 确定性生成，不调用任意代码；
- 推荐数量有上限，且仅基于当前会话、结果类型和已开放能力；
- 运行中的 Turn 不生成可误触的推荐；
- 目录类推荐不会声称拥有原始样例数据访问权限；
- 点击推荐提交正常用户消息，并携带 suggestion_id 写入审计记录。

### 验收标准

- 推荐文字本身就是可以执行的下一轮问题；
- 推荐不绕过权限、确认、语义模型或查询安全门禁；
- 服务端能追溯推荐来源与实际提交；
- 推荐失败不影响用户手动继续提问。

## 5. M7.6 描述统计与受限图表

### 后端分析产物

- Planner 在适用查询中声明 analysis.describe 与 visualization.compose 步骤；
- 标量或不适用结果将派生步骤标记为 skipped，不会伪造图表；
- 多行已验证结果生成 analysis_summary，包括数值列计数、空值、最小值、最大值、均值、中位数和标准差；
- 图表生成 chart_spec，支持折线、柱状、横向柱状和散点四种受限类型；
- 两类派生产物均记录源 artifact_id、源 evidence_id、变换版本、摘要哈希和验证结论；
- Run context 与完成事件返回派生产物 ID，便于刷新后可靠定位。

### 前端渲染

- ECharts 使用 core 模块与 SVG renderer，按需注册图表类型；
- 渲染前校验 ChartSpec 版本、图表类型、字段存在性、字段类型和行数上限；
- 数据来自匹配 source_artifact_id 的可信查询产物；
- 页面同时展示描述统计卡片、图表、查询表格和证据定位；
- ChartSpec 不能携带函数、任意 option 或脚本。

### 安全边界

- 不执行模型生成代码；
- 不允许图表直接读取数据库；
- 不允许未验证数据绕过 Query Artifact；
- 不允许图表扩大查询行数或访问其他工作空间；
- 报告导出仍未开放，不在能力回答中提前承诺。
