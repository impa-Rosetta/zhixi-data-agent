# ADV-B1：建模任务协议与依赖基础

日期：2026-09-28。依据已批准的高级分析三批规格第二批 B1。此切片完成核心协议及依赖准备，不是六算法训练/推理交付。

## 实现内容

新增 `packages/modeling/contracts.py`，当前仅验证数据，不实例化或训练模型，不访问数据库/文件，不执行生成代码，也没有新增对话工具或网页入口。

- ModelSpec：固定六类算法、算法对应任务、来源产物/快照 UUID、SHA256、最多50个特征、目标、随机/时间/分组划分、随机种子、验证比例和超参数。
- 算法参数白名单：线性回归无开放参数；决策树 max_depth 1–20/min_samples_leaf 1–100；森林 n_estimators 10–500；逻辑回归 C>0且<=100/max_iter 100–2000；KMeans n_clusters 2–10/max_iter 100–1000；Isolation Forest contamination>0且<=0.5。默认参数由代码声明并可显式导出。
- 拒绝未知属性、导入路径、SQL/Python/模型路径、n_jobs 等执行控制；严格拒绝数值字段中的布尔和字符串伪装。预测允许原始文本类别，不将其作为代码。
- 监督任务必须提供目标，无监督任务不接受目标。目标、时间/分组元数据不得作为输入特征；未来预测必须时间划分。分组与时间联合划分暂不支持，不能静默退回随机划分。
- PredictionRequest：最多20,000行、50字段、20MiB编码输入，有限数值/有界字符串/空值，所有行字段一致。推理时必须与已授权模型版本的实际特征集合匹配；本协议自身不提供授权。
- ModelFileManifest：只接受内部 skops 格式、内容摘要、非零且不超过20MiB的文件大小和四项精确依赖版本。不允许客户端提供文件路径、pickle格式或trusted_types。
- ModelTrainingResult/EvaluationMetric：任务与指标匹配、样本/划分计数一致、最低样本数、监督基线必需、指标范围和空指标原因。负R²合法，无定义指标不得写成0；异常检测只允许异常占比，不承诺无标签准确率。

这些检查不是实际计算、来源授权或安全加载的替代品。真实样本类别要求、混淆矩阵/标签/预测明细、数据划分及泄漏检验由后续数据准备与训练执行模块完成，发布时还必须重新验证全部输出与摘要。

## 依赖

通过 PyPI 官方元数据核对 Python 3.12兼容性，加入生产依赖并更新uv.lock：scikit-learn 1.9.1、skops 0.16.0、numpy 2.5.3、scipy 1.18.1。不是仅安装在开发环境。未来专用训练镜像须沿用这些版本；API/通用Worker仍不得执行训练或持有Docker socket。

选型依据：[scikit-learn 模型持久化](https://scikit-learn.org/stable/model_persistence.html)说明模型加载的信任与版本兼容边界；[数据泄漏与Pipeline](https://scikit-learn.org/stable/common_pitfalls.html)说明先拆分再拟合预处理。本次没有实现skops加载，不能宣称文件已安全反序列化。

本地安装四项及传递依赖成功，pip-audit --local --skip-editable未发现已知漏洞；不意味着不存在未知漏洞。uv lock --check通过。

API/Worker Linux镜像均实际构建成功。Worker镜像在无网络、只读根目录、丢弃capabilities、禁止提权、512MiB/1CPU/64PID的非root容器中成功导入六类估计器及skops，读取四项版本与锁定值一致；这只是依赖加载验证，不是隔离训练/超时/模型保存验收。
