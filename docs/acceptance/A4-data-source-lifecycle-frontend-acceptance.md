# A4 数据源生命周期前端验收

- 验收日期：2026-09-06
- 验收范围：配置编辑、凭据轮换、连接复测、停用、启用、软删除保护
- 结论：通过

## 交付内容

- 数据源详情页新增生命周期管理区域，可编辑名称、说明、地址、端口、数据库名与 TLS 策略；
- 前端只 PATCH 实际发生变化的字段，继续携带当前版本，由后端乐观锁裁决并发修改；
- 连接字段变化由后端自动创建真实连接检测任务，运行中的检测与配置更新竞态由状态机拒绝；
- 凭据永不回显；留空即保留现有密文，轮换时账号与密码必须成套提交，密码在成功或失败后立即清空；
- 切换到证书校验模式必须同时提供 CA 证书，关闭 TLS 会显示风险警告；
- 重新检测、停用、启用、删除均调用真实 API；停用和删除需要二次确认，删除还必须精确输入数据源名称；
- 删除由后端执行软删除并销毁密文，完成后返回数据源列表。

## 真实链路验收

在本地 Compose 的真实 PostgreSQL 数据源上完成可逆验收：

1. PATCH 临时名称并 GET 回读，确认版本递增；
2. PATCH 恢复原名称；
3. POST 停用并 GET 回读 disabled；
4. POST 启用，等待真实 connection_test 经 Outbox 与 Worker 完成；
5. 最终数据源恢复 ready，原活动目录保持存在。
