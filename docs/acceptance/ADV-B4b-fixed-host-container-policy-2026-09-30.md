# 受信任主机执行器容器策略基础（B4b）

日期：2026-09-30。依据已批准的高级分析与建模规格。本批仅生成不可由用户输入改变的容器创建参数；没有启动长期运行的主机代理。

固定策略要求：已核对的本地镜像SHA256 ID、代码生成的容器名、独立尝试目录；无网络、只读根目录、UID/GID 10001、禁止权限提升、丢弃全部 capabilities、2 CPU、1 GiB 内存与交换上限、128 PID、临时空间128 MiB；只读挂载输入，单独挂载输出，不挂Docker socket。用户或LLM不能提供镜像标签、挂载路径或额外容器参数。

6项专项测试覆盖固定资源边界、用户提供镜像/恶意容器名拒绝、相对路径和缺失独立目录拒绝。Ruff、严格MyPy及专项测试通过。

明确边界：当前Docker Desktop引擎不可用，本批没有在当前机器复验真实容器参数；9月29日的16次真实训练/推理验收属于较早镜像/脚本。生产主机代理的任务ID领取、超时与取消监测、输出20 MiB文件系统硬限额、对象发布及恢复仍未实现。此策略模块不属于API或普通Worker，并未开放模型工具。
