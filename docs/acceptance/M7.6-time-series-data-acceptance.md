# M7.6 时间范围与趋势数据验收记录

- 验收日期：2026-09-19
- 验收范围：相对时间范围执行、时间序列结果、示例数据库、容器构建可靠性

## 验收结论

“最近三个月不良率 → 按月份展开 → 折线图”已从单点占位结果修复为真实三点时间序列。Agent 会把自然语言时间范围绑定到已发布语义模型的时间维度，在查询执行前生成参数化的半开区间过滤条件；图表和统计仍只从验证后的查询产物派生。

## 实现方案

1. 相对时间解析以 AnalysisRun 的 `created_at` 为固定基准，支持本月、上月、今年、去年、最近/近 N 个月和最近一年，避免重试或跨天执行产生漂移。
2. Planner 只在所选指标存在唯一兼容时间维度时写入 `time_dimension`；无法唯一确定时受控失败，不猜测物理字段。
3. Worker 将解析结果转换为 `gte start` 与 `lt end` 两个 QueryFilter，继续经过语义编译、AST 校验、参数绑定和验证 ID 执行链路。
4. 已完成结果将解析后的起止时间投影到白名单会话上下文，后续比较、解释和细化可复用同一时间语义。
5. 查询执行器把数据库 Decimal 规范化为 JSON number；分析引擎兼容历史数值字符串。若结果只有一个时间点，Agent 会明确说明无法形成可信趋势，不再把单点描述成折线趋势。
6. PostgreSQL 与 MySQL 示例库均扩展为 12 个自然月、24 条质检记录；最近三个月不良率为 1.75%、2.75%、3.00%。
7. API 与 Worker 镜像复制源码后直接从 `/app` 加载，不再重复构建安装本项目，避免源码更新时因 PyPI 短时不可用导致启动失败。
