# M8-E4a 真实模型预算闸门底座验收

- 日期：2026-09-27
- 状态：底层预算/计量能力已实现并在合成环境验收；真实模型基准产品入口仍关闭，未发起付费调用。

## 设计边界

1. 只有已在数据库标记为 `live/running` 的受控运行可占用额度；当前公开 API 仍拒绝 live 轨道，UI 仍标注未开放。此底座不能被视为完整 E4。
2. 调用前在事务内原子预留一次调用和保守估算 token；限制调用数、token 和最长时长。请求只落 SHA-256 摘要与合成测试键，不落提示词、供应商正文或密钥。
3. 评测专用 DeepSeek 网关关闭自动传输重试；结构化回答如需修复，必须重新占用一次额度。流式接口拒绝，不能绕开预算。
4. 收到合法 usage 才结算调用/实际 token；超出本地估算时记录真实用量并阻断下一次调用，不谎称供应商计费的绝对上限。超时、5xx、缺失 usage、进程崩溃的悬挂回执均标记 `usage_uncertain`，保留占额并暂停运行，不自动重发/退款。
5. 事务幂等键拒绝同一运行内重复发送；迟到响应在看门狗已暂停后不发布为成功。

## 验证

- PostgreSQL 迁移 `20260927_0014` upgrade → downgrade → upgrade 成功；新增受工作空间约束的调用回执表和非负占额约束。
- 隔离 PostgreSQL 上两线程竞争仅一个预留成功、另一个被预算阻断；结算一次后重复结算不增加使用量。测试创建的合成用户/工作空间/运行在结束时按精确 ID 清理。
- `httpx.MockTransport` 的合成供应商响应覆盖正常用量、重复投递、超时、5xx、缺用量、修复请求另计、模型版本不符、三种预算上限、迟到响应、悬挂回执回收和流式绕过。
- 全量后端 433 通过、1 跳过（可选 PostgreSQL 测试无环境变量时）；单独开启合成 PostgreSQL 环境后该测试通过。MyPy 119 个文件、Ruff、前端 68 项、ESLint/TypeScript 均通过。
