## 交付范围

- 澄清请求作为持久化 Agent 消息直接提问，候选项作为快捷回复，自由输入保持可用；
- 权限不足、数据/语义条件不足、能力越界和临时故障由后端安全模板转换为自然语言；
- 内部错误码保留在消息技术元数据和运行审计中，不再作为主对话内容；
- 能力说明、授权目录结果和指标查询结果均生成持久化 Agent 回答；
- 查询异常优先读取结构化 `code`，`query.mapping_incomplete` 不再退化为 `agent.execution_failed`；
- 执行失败时同步关闭运行中的步骤，避免界面残留“仍在执行”；
- 历史运行没有 Agent 消息时，Web 使用不包含原始错误码的安全回退文案；
- 宽泛目录问法覆盖“数据库里有哪些表”“表里有啥”等常见表达；
- Decimal 及序列化 Decimal 去除无意义尾零，保留真实数值。
