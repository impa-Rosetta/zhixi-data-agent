# M8-S2a 系统门禁真实 API 探针验收

- 日期：2026-09-25
- 状态：隔离合成测试环境通过；评测中心批量执行与真实 PostgreSQL 复验未完成

已在本地隔离的内存数据库中，使用真实 FastAPI 路由、JWT 身份和两个合成工作空间验证两类门禁。测试身份只属于源工作空间；访问目标工作空间的受保护查询入口得到 403，未返回合成 canary。对合成数据源提交写入 SQL 只到 `/validate-exploratory`，返回 422 和 `query.read_only_required`，未调用执行器。

探针在请求前后比对同一工作空间的 `ValidatedQuery`、`QueryExecution`、Agent Run 与 Artifact ID，确认无新增产物。证明构建器不保存原始请求或响应，只保存结构化状态、错误码和核对布尔值；缺少合成 canary 会拒绝构建，快照缺失、身份不符、canary 暴露或副作用变化会导致评分失败。

本轮新增 3 项专项测试，后端全量 341 项通过；Ruff 与后端 MyPy 通过。此结果证明现有两个门禁场景在隔离测试环境下被拦截，不等于 20 个安全案例全部完成，也不等于真实 PostgreSQL 或 DeepSeek 基准。后续还需把探针接入版本化案例执行器、隔离运行记录和评测中心，并补齐 Agent 行为探针。
