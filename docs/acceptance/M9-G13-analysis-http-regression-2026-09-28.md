# M9-G13 分析与持续会话HTTP回归批次

日期：2026-09-28。基线`5a707bf`。在用户确认接口回归方案后实施；只新增测试与本记录，不修改生产行为、权限规则、CI阈值或模型配置。

## 范围与结果

新增`tests/test_analysis_http_regression.py`，21项全部通过（4.65秒）。使用真实FastAPI路由、认证、SQLAlchemy及隔离内存SQLite；测试服务不启动Worker、不访问用户数据库、不调用付费模型。

- 五角色：四种具有分析权限的角色可浏览和创建会话；审计员拒绝创建、浏览分析详情、消息、确认、重试、取消与分析事件，拒绝后领域记录数量不变。不放宽审计员权限。
- 撤权：移除成员关系后，原访问token仍无法读取详情、追问或连接事件流；没有新增会话、轮次、运行、消息、事件或Outbox。
- 双空间：同一用户是两个空间管理员时，仍不能在另一个空间的地址下读取或操作原空间的会话/运行；返回404稳定错误码，不产生领域副作用。
- 持续追问：重复提交同一个幂等键只产生一次第二轮，conversation ID不变；运行中的后续轮次先排队，不并行生成第二条Outbox。分页恢复两轮消息及顺序。
- 补充说明：澄清、确认等待、可重试失败三个状态均能在原轮次接受消息并恢复；重复消息不增加任务；非确认状态清除旧绑定，确认状态保留等待执行的上下文。
- 状态门禁：归档会话和非活动轮次拒绝操作；queued运行不能重试、确认或追加澄清，409拒绝不留部分领域写入。
- 确认与重试：批准只调度一次，拒绝取消且不新增Outbox；可重试失败恢复原执行节点并清除错误码，再次重试拒绝。
- 事件游标：运行流拒绝非法/负数Last-Event-ID；会话流拒绝非整数，after与Last-Event-ID取较大值，响应保持SSE和禁缓冲头。会话流成功分支使用有限流替身，仅证明路由游标传递，不声称真实持续流/断线恢复验收；实际运行事件重放保留既有测试证据。
