# M7.7-B1a 异步报告生成核心验收

- 日期：2026-09-20
- 范围：Worker 状态机、Markdown/HTML/PDF 渲染、MinIO 发布、摘要、重试分类与审计

## 已完成

1. 新增报告任务 `analysis_reports.generate`，由事务 Outbox 分发；
2. 使用条件状态转换领取 queued 报告，重复消费不会重复生成已完成报告；
3. 固定生成 Markdown、受控 HTML 和 PDF 三种格式；
4. HTML 使用固定 CSP、离线 CSS 和 Noto Sans CJK 中文字体栈；
5. PDF 渲染器禁止外部 URL 访问，避免渲染阶段网络取数；
6. 三种文件分别计算 SHA-256，并使用内容摘要构造确定性私有对象键；
7. MinIO 上传成功后在单一事务中写入文件元数据、完成状态和成功审计；
8. 渲染或存储故障转换为稳定错误码，支持最多两次指数退避自动重试；
9. Worker 镜像固定 WeasyPrint 66.0、Pango 和 Noto CJK 依赖；
10. Worker 与 Scheduler 显式等待 MinIO 健康。
