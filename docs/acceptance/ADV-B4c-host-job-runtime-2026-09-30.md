# 受信任主机任务执行流程（ADV-B4c）

日期：2026-09-30。范围为**内部主机进程**按持久化任务 ID 运行训练，不是面向用户开放的 API，也不是已经部署的常驻服务。

实现：主机只接收任务 UUID；从数据库读取规格及快照回执，当前授权后 CAS 领取租约；从对象存储读取并校验冻结快照；创建一次性私有输入/输出目录；使用 B4b 固定 Docker 参数和已核对 SHA256 镜像 ID 创建、启动容器；轮询数据库取消状态与来源权限，300 秒超时；仅接受固定结果文件集合，核验输出任务/尝试 ID、结构化结果、模型字节摘要，再次检查授权并事务性发布版本。执行失败记录安全错误码，不把异常堆栈或数据送回用户。容器移除和临时目录清理由主机负责。

离线测试用受控执行器替身调用真实固定算法实现，覆盖：成功训练与不可变版本发布、执行失败、训练后撤权阻止发布、用户取消阻止发布；另有 B4b 六项参数策略测试。全量后端 999 通过、1 项跳过，覆盖率 90.60%；Ruff 与严格 MyPy 通过。

**未验收/不得宣称完成：** 当前 Docker Desktop 引擎不可用，这四项是离线主机编排测试，并非本机真实 Docker 启动测试；对象存储是内存替身而非真实 MinIO；没有长期运行的任务轮询代理、宿主级文件系统硬限额、重启恢复/租约续期/多主机竞争验收，也没有 API、Worker、会话、报告或浏览器建模入口。镜像 ID 必须由部署配置校验，不可由用户提交。此代码不放在 API 或普通 Worker 进程运行。
