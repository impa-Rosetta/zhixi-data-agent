# B2d 训练数据快照与对象存储边界

日期：2026-09-29。沿用已批准的三批建模方案。

## 完成范围

新增 packages/modeling/snapshots.py，冻结 ModelSpec、来源证据 ID 和完整查询数据为 UTF-8 JSON 字节，记录 SHA256、输入总数、有效数和丢弃数。模型输入不接受路径或执行文本，编码后仍检查 20 MiB 上限。

读回时验证字节摘要、严格格式版本、任务规格及来源证据，再通过当前授权读取器和数据准备模块重验。即使攻击者修改内容并重算外层摘要，内部来源摘要、当前证据和任务规格仍须一致。快照不会保持对原始可变行集的引用。

新增 packages/modeling/snapshot_storage.py，适配 put/get 对象存储接口。对象键只由空间 UUID、随机快照 UUID 与摘要生成，不接受客户端路径；每次保存使用不同快照 ID，不覆盖旧对象。读前检查空间与当前授权，取回后核验大小/摘要并再次检查来源。

SnapshotReceipt 仅为服务器内部记录，不是 API 凭证。调用者必须使用当前空间绑定的 load_training_source 构造读取闭包；不能让客户端自报空间与授权读取结果。数据库中持久化 receipt、租约与发布事务属于 B5。

## 验证

先跑缺少快照模块的失败测试，再实现。15 项专项通过：冻结复制、往返、摘要损坏、重哈希篡改、非法版本与格式、撤权、跨空间、唯一对象键、对象长度变化。建模包严格 MyPy 和新增文件 Ruff 通过。

对象存储测试使用内存适配器，尚未在真实 MinIO 上验收。未添加用户可调用的快照接口，没有修改业务数据库或公开原始数据。

## 未完成范围

B2 尚未整体关闭。此片完成快照编解码和存储边界，不代表专用大行集查询、快照数据库记录或实际 MinIO 联合验收已完成。已有读取器依然只接受完整可信 query_result，拒绝截断结果，不会将普通分页结果当完整训练集。

后续仍需专用完整数据提取、训练 Pipeline、基线评估、隔离代理、持久化任务/模型版本及持续会话入口。六算法尚不能在网页执行。
