# M8-E3d 评测历史趋势切片验收

日期：2026-09-28。用户明确批准“最近最多30次同版本、同数据、同模型”方案后实施。本切片不关闭整个 M8 或 M9。

## 实现

- 评测详情展示最近第一页（最多30次）中可比的已完成运行；即使用户切换运行列表分页，趋势仍读取最近第一页。
- 可比条件包括同工作空间、轨道、案例集版本及摘要、数据集、语义版本、模型、工具和提示版本。不同冻结条件的运行不连线；未完成运行不入图。
- 有限且位于0至1的真实汇总比例才进入图表；缺失、字符串、NaN、无穷和越界数值不推定为零。不足两次有效记录显示“暂无可比趋势”，加载/请求失败分别提示，不伪造历史。
- 原生SVG显示覆盖率与已评估通过率，按时间排序，以运行顺序等距排列（明确说明非等时间间隔），并提供可读取的时间/比例表。未评估案例不计入已评估通过率；运行详情的安全失败警示保持不变。
- 无新后端接口、数据库迁移或付费调用；复用原有受权运行列表。
